# 我的课包订单

> 本人课包订单列表：按下单时间倒序最多 50 条，逐行补状态文案与课包/规格/学生名称。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| API Key | `app/school/order/list` |
| 接口地址 | `POST /api/app/school/order/list` |
| 请求方式 | POST |
| 是否需登录 | 是 |
| 所属模块 | 拓展应用（app） |
| 所属控制器 | Order（教务-课程套餐订单（移动端，需登录）） |
| 登录方式 | 请求头携带 `token`（登录接口返回） |
| 来源 | 后端控制器（未在 mobile `api_list.js` 中定义） |

## 请求参数

无请求参数。

## 请求头

| Header | 说明 |
| --- | --- |
| token | 用户登录凭证，登录成功后由 `user/info/login` 返回，前端自动携带 |

## 请求示例

```bash
curl -X POST '{apiUrl}app/school/order/list' \
  -H 'Content-Type: application/json' \
  -d '{}'
```
