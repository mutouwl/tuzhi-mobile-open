# 积分规则页：通用规则 + 签到规则说明

## 基本信息

| 项目 | 内容 |
| --- | --- |
| API Key | `app.score.rule` |
| 接口地址 | `POST /api/app/score/center/rule` |
| 请求方式 | POST |
| 是否需登录 | 是 |
| 所属模块 | 拓展应用（app） |
| 所属控制器 | Center（学员端积分中心：余额 / 任务 / 领取 / 规则） |
| 登录方式 | 请求头携带 `token`（登录接口返回） |

## 请求参数

无请求参数。

## 请求头

| Header | 说明 |
| --- | --- |
| token | 用户登录凭证，登录成功后由 `user/info/login` 返回，前端自动携带 |

## 请求示例

```bash
curl -X POST '{apiUrl}app/score/center/rule' \
  -H 'Content-Type: application/json' \
  -d '{}'
```
