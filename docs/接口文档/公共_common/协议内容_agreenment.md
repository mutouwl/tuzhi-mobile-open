# 协议内容

> 用户协议

## 基本信息

| 项目 | 内容 |
| --- | --- |
| API Key | `common.agreenment` |
| 接口地址 | `POST /api/common/agreenment` |
| 请求方式 | POST |
| 是否需登录 | 否 |
| 所属模块 | 公共（common） |
| 所属控制器 | Common（公共接口） |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| type | string | 否 | 类型 | `privacy` |

## 请求示例

```bash
curl -X POST '{apiUrl}common/agreenment' \
  -H 'Content-Type: application/json' \
  -d '{"type":"privacy"}'
```
