# 学员申请连麦

> 观众（学员）在直播间主动发起连麦申请，记录置为「申请中」，中控台实时收到待处理申请。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| API Key | `live.link.apply` |
| 接口地址 | `POST /api/live/link/apply` |
| 请求方式 | POST |
| 是否需登录 | 是 |
| 所属模块 | 直播（live） |
| 所属控制器 | Link（直播连麦 - 用户端 学员申请/接受/拒绝/下麦 + 讲师同意/邀请（讲师通过 is_lecturer 进入，复用 api auth）） |
| 登录方式 | 请求头携带 `token`（登录接口返回） |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| course_id | integer | 是 | 直播课程ID（为 0 报「参数错误」） | `1585` |
| link_type | integer | 否 | 连麦模式：1视频（默认） 2语音；其他值报「连麦模式不正确」 | `1` |
| platform | string | 否 | 请求端 pc / mobile；对应端开关关闭报「当前端不可用连麦」，不传默认放行 | `mobile` |

## 请求头

| Header | 说明 |
| --- | --- |
| token | 用户登录凭证，登录成功后由 `user/info/login` 返回，前端自动携带 |

## 请求示例

```bash
curl -X POST '{apiUrl}live/link/apply' \
  -H 'Content-Type: application/json' \
  -d '{"course_id":1585,"link_type":1,"platform":"mobile"}'
```

## 返回示例

> 暂无真实返回数据。

## 返回参数说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | integer | 状态码：1=成功，0=业务错误，401=未登录 |
| msg | string | 提示信息 |
| data | object | 业务数据 |
| data.link_id | integer | 新建的连麦记录ID（status=0 申请中、inviter=2 学员申请） |

## 备注

- 申请成功只代表进入排队，不代表已接通；需讲师同意（live/link/agree）后学员端通过轮询或实时消息感知
- 同一场直播同时只允许 1 人连麦；学员申请不占上限，接通（accept/agree）时才校验名额
- 常见失败：暂未订阅该课程 / 仅真实直播支持连麦 / 消息服务未开启，无法连麦 / 讲师未开启直播连麦 / 讲师已开启禁止主动连麦，可等待讲师邀请 / 你已被禁止申请连麦，可联系机构解除 / 你已有一条进行中的连麦
- 依赖开关：连麦全局主开关、PC/移动端开关、通用设置「消息服务状态」、本场直播间连麦开关
